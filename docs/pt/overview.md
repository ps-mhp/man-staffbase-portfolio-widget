# Portfólio

O widget «Portfólio» apresenta uma série de mosaicos lado a lado. Cada mosaico
contém uma imagem, um título e, quando clicado, redireciona para uma página — dentro
da aplicação ou para um site externo. É adequado em qualquer situação em que vários
devem aparecer lado a lado: gamas de produtos, departamentos, pontos de contacto.

O Staffbase inclui um widget deste tipo, mas apenas no editor clássico. Este
widget é a réplica para o editor Studio. Tem exatamente o mesmo aspeto e pode
ainda apresentar uma etiqueta de categoria acima do título.

## O que os leitores veem

Uma série de mosaicos com a mesma largura, que se ajustam em ecrãs estreitos. Cada
mosaico tem uma imagem na parte superior e, por baixo — dependendo da configuração —, uma pequena
etiqueta de categoria, o título e uma breve descrição. No canto superior direito aparece uma
seta, desde que o mosaico tenha um destino.

Ao passar o rato por cima, a moldura torna-se mais marcante e o título e a seta
ficam a vermelho. Todo o mosaico é o link, não apenas o título.

## O que vê no editor do CMS

No editor, os mosaicos aparecem exatamente como na página. No entanto, as ligações
não estão ativas — para verificar os destinos, abra a pré-visualização.

Atualmente, os blocos são geridos como uma lista JSON num campo de texto. Está
previsto um editor de blocos específico; o formato permanecerá inalterado.
